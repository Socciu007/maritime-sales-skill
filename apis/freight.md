# 运价 API

## 接口信息
- **方法**：POST
- **地址**：`https://www.dadaex.cn/api/interface/freight/getOceanfreightToChatNolink`

## 入参

| 参数 | 说明 | 是否必填 | 格式/说明 |
|------|------|---------|------|
| start_port | 起运港 | 必填 | 港口英文名小写，如 `shanghai` |
| end_port | 目的港 | 必填 | 港口英文名小写，如 `singapore` |
| hhtime | 货好时间 | 选填 | `YYYY-MM-DD`，未提及传 `""` |
| etd | 预计开船时间 | 选填 | `YYYY-MM-DD`，未提及传 `""` |
| carrier | 船公司 | 选填 | 船公司英文名大写，如 `MAERSK`，未提及传 `""` |
| userId | 用户ID | 必填 | 从 session 提取数字部分，如 session=`agent%3Amain%3A975` → `975` |


> QQ 和 requireSailingSchedule 字段忽略不传

## 出参结构总览

接口返回包含两部分：
- `data[]`：运价主体列表（主报价）
- `extendInfo.surcharge[]`：附加费明细（本地费用）

> 字段名以接口原始返回为准，区分大小写，不要自行改名。

## 运价主体字段字典（`data[]`）

| 字段 | 说明 | 示例/用途 |
|------|------|---------|
| 运价ID | 运价唯一标识 | 如 `5579882` |
| 起运港 | 起运港英文名 | 如 `SHANGHAI` |
| 起运港码头 | 起运港码头信息 | 如 `WGQ4(外四)` |
| 目的港 | 目的港英文名 | 如 `SINGAPORE` |
| 目的港码头 | 目的港码头信息 | 可能为空字符串 |
| 目的港代码 | 目的港代码 | 如 `SGSIN` |
| 中转港 | 中转港信息 | 可能为空，或如 `SINGAPORE` |
| 备注 | 运价备注 | 如 `OBS USD30PER TEU Included` |
| 航线代码 | 航线代码 | 如 `KCS`，可复用给舱位API.routeCode / 船期API.routeCode |
| 20GP实价 | 20GP报价 | 如 `$525` |
| 40GP实价 | 40GP报价 | 如 `$1000` |
| 40H0实价 | 40HQ报价（接口原字段名为 `40H0实价`） | 如 `$1000` |
| 暗放价 | 暗放价格 | 可能为空 |
| 底价 | 底价 | 可能为空 |
| 航线名称 | 航线名称 | 如 `东南亚线`，可复用给舱位API.route |
| 船司 | 船公司 | 如 `ONE` |
| 生效日期 | 运价生效日期 | `YYYY-MM-DD` |
| 开航日期 | 预计开航日期 | `YYYY-MM-DD` |
| 船期 | 开船周期 | 如 `TUE` |
| 航程天数 | 航程天数字段 | 如 `9` |
| 航程 | 航程展示字段 | 如 `9 天` |
| 重要提示 | 销售提示信息 | 如 `特价/最便宜最低报价` |
| 中转类型 | 直达/中转类型 | 如 `直达(DIRECT)`，可参考用于舱位API.type |
| 最低报价 | 是否最低报价 | `true` / `false` |
| 现舱 | 舱位状态 | 为空或如 `有舱`，可作为紧张信号 |

| 舱名 | 舱位名称 | 如 `AS PATRIA 2604S` |

| 免箱期(freetime) | 免箱期信息 | 如 `3DEM+5DET`，销售加分项 |

## 附加费字段字典（`extendInfo.surcharge[]`）

| 字段 | 说明 | 示例 |
|------|------|------|
| 费用名称 | 中文费用名称 | 如 `码头操作费` |
| 费用英文名称 | 英文费用名称 | 如 `Dock Handling Fee` |
| 币种 | 费用币种 | 如 `CNY` |
| 单位 | 计费单位 | 常见为 `箱` 或 `票` |
| 20gpSell | 20GP费用（单位=箱时） | 如 `541` |
| 40gpSell | 40GP费用（单位=箱时） | 如 `828` |
| 40hqSell | 40HQ费用（单位=箱时） | 如 `828` |
| 单票价格 | 单票费用（单位=票时） | 如 `450` |
| 备注 | 附加费备注（如存在） | 如 `可做SEAWAY` |

附加费取值规则：
- `单位=箱`：读取 `20gpSell` / `40gpSell` / `40hqSell`
- `单位=票`：读取 `单票价格`
- `备注` 存在时保留展示

## 对客回答策略（避免堆字段）

- 默认执行“最小必要信息”原则：只回答客户问题直接相关字段。
- 未被客户问到的技术字段（如 `运价ID`、`目的港代码`、`起运港码头`）默认不主动展示。
- 只有客户明确要求“完整明细/全部字段/原始返回”时，才输出全字段。
- 字段为空时不展示该字段，除非客户追问该字段。
- 若客户只问单点（如“有没有舱位”），先回答结论，再补充 1-2 个相关字段。

### 标准报价（默认对客展示）

简洁版默认字段（按此顺序输出）：
- 船公司（`船司`）
- 航线（优先 `航线名称`，缺失时用 `航线代码`）
- 航线代码（`航线代码`）
- 船期（`船期`，即周几，如 `TUE`）
- 中转/直达（`中转类型`）
- 运价（`20GP实价` / `40GP实价` / `40H0实价`，接口原字段名）
- 航程（优先 `航程`，缺失时用 `航程天数`）
- 舱位（`现舱`）
- 免箱期（`免箱期(freetime)`）
- 备注（`备注`，偏费用或条款补充）
- 重要提示（`重要提示`，偏销售结论，如特价/最低报价）

展示规则：
- 上述字段默认按顺序组织，不要打乱。
- 字段有值才展示；为空时可不展示该字段。
- `开航日期` 默认不主动展示，客户明确询问具体日期时再补充。

### 附加费展示策略

- 默认只给摘要：是否有本地费、计费币种、主要费项。
- 客户问“附加费明细/本地费明细”时，再逐条展开 `surcharge[]`。
- 若客户只关心某箱型（如只问 40HQ），附加费也只展示对应箱型价格。

### 对客输出模板（可复用）

**简版（默认）**
- 船公司：`船司`
- 航线：`航线名称`（无则 `航线代码`）
- 航线代码：`航线代码`
- 船期：`船期`（周几，如 `TUE`）
- 中转直达：`中转类型`
- 运价：20GP `20GP实价` / 40GP `40GP实价` / 40HQ `40H0实价`
- 航程：`航程`（无则 `航程天数`）
- 舱位：`现舱`
- 免箱期：`免箱期(freetime)`
- 备注：`备注`
- 重要提示：`重要提示`

**明细版（客户明确要求时）**
- 在简版基础上，补充：`航线代码`、`航次`、`舱名`、`晚开日期`、`备注`、`surcharge[]` 逐条明细。

## 空值与异常处理

- 价格相关字段可能为空字符串，按空值处理，不要抛错。
- `extendInfo` 或 `surcharge` 可能不存在，兜底为空对象/空数组。
- `status=0` 或无数据：`暂时没有查到相关运价，请稍后重试或换个条件查询。`
- 网络超时：`查询超时，请稍后重试。`
- 返回异常：`运价查询出现问题，请稍后重试。`

## 调用示例

```json
{
  "start_port": "shanghai",
  "end_port": "singapore",
  "hhtime": "",
  "etd": "2026-04-20",
  "carrier": "MAERSK",
  "userId": "975"
}
```

## 错误处理
任何情况下不能卡住，统一处理：
- status=0 或无数据 → "暂时没有查到相关运价，请稍后重试或换个条件查询。"
- 网络超时 → "查询超时，请稍后重试。"
- 返回异常 → "运价查询出现问题，请稍后重试。"

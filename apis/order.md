# 订单查询 API

## 接口信息
- **方法**：GET
- **地址**：`https://www.dadaex.cn/api/seaOrder/chatOrder`

## 入参

| 参数 | 说明 | 是否必填 | 格式/示例 |
|------|------|---------|---------|
| blNo | 单号（EB号或提单号） | 条件必填 | JSON数组字符串，如 `["FYEB088797-120160"]` 或 `["ONEYSHAG72304600","KMTCSHAP503825"]` |
| portname | 目的港 | 条件必填 | 大写英文，如 `SINGAPORE` |
| carrier | 船公司 | 选填 | 大写英文，如 `KMTC` |
| vessel | 船名 | 选填 | 如 `CALLAO BRIDGE` |
| voyage | 航次 | 选填 | 如 `0291S` |
| line_code | 航线代码 | 选填 | 如 `KCS` |
| start_time | 订单创建时间范围-开始 | 选填 | `YYYY-MM-DD`，不筛选传 `""` |
| end_time | 订单创建时间范围-结束 | 选填 | `YYYY-MM-DD`，不筛选传 `""` |
| etd_time | ETD时间筛选 | 选填 | `YYYY-MM-DD`，不筛选传 `""` |
| userId | 用户ID | 必填 | 从session提取，同舱位API |
| groupId | 组ID | 忽略 | 传 `""` |
| idCindy | 固定参数 | 必填 | 固定传 `true` |
| yp | 固定参数 | 必填 | 固定传 `0` |

> ⚠️ **不可无参调用**：blNo / portname / carrier / vessel / voyage 至少提供一个，否则必须先追问客户

## 单号类型识别

| 格式特征 | 类型 | 示例 |
|---------|------|------|
| `FYEB` 开头，含连字符 | EB号（订单编号） | `FYEB088797-120160` |
| 其他格式（船司代码+港口+数字） | 提单号 | `ONEYSHAG72304600`、`177IAHAHS2005852` |

两种单号都用数组格式传入 blNo，无需区分接口。

## 错误处理规则（重要）

API 调用后必须先检查返回的 `status` 字段，再决定如何回复，**任何情况下都不能卡住不回复**：

| 情况 | 处理方式 |
|------|---------|
| status=1，data 有数据 | 正常解析回复 |
| status=0，"未查询到数据" | 回复："没有查询到相关订单，请确认单号是否正确。" |
| status=0，其他错误信息 | 回复："查询暂时遇到问题，请稍后再试。" |
| data 为空数组 | 回复："暂时没有找到相关订单记录。" |
| 网络超时 / 连接失败 | 回复："系统响应超时，请稍后重试。" |
| userId 不存在（返回空数据） | 回复："没有查询到订单，如持续无法查询请联系管理员确认账号配置。" |
| 任何未知异常 | 回复："查询出现异常，请稍后重试或联系客服。" |

**原则：宁可给一句友好提示，也不能沉默卡住。**

```
# 按EB号查询
GET .../chatOrder?blNo=["FYEB088797-120160"]&userId=001&groupId=&idCindy=true&yp=0

# 按提单号查询
GET .../chatOrder?blNo=["ONEYSHAG72304600"]&userId=001&groupId=&idCindy=true&yp=0

# 按目的港查询
GET .../chatOrder?blNo=&portname=SINGAPORE&userId=001&groupId=&idCindy=true&yp=0&start_time=&end_time=&etd_time=&carrier=&line_code=&vessel=&voyage=

# 按船名+航次查询
GET .../chatOrder?blNo=&vessel=CALLAO BRIDGE&voyage=0291S&userId=001&groupId=&idCindy=true&yp=0
```

## 出参字段分类

> ⚠️ **重要设计**：出参的很多字段 key 本身就是自然语言问句（如"上船了吗"、"可以报关吗"）。
> 解析策略：根据客户的问题做**语义匹配**，找到对应字段的 value 直接回答，**不要把所有字段全部输出**。

| 几票订单 | 如"共有3订单" |
| 有哪些订单 | 数组，关联的所有单号 |

## 数组字段处理规则

以下字段在多箱时会返回数组（每箱一条），需逐条展示：
- `进港时间`：`["箱号: 时间", "箱号: 时间", ...]`
- `VGM重量`：`["箱号: 重量(状态)", ...]`
- `箱号`：单个字符串，多箱时只显示第一个（其余可查明细）

## 舱单截图字段说明

`舱单发了吗？...` 字段的 value 有两种形态：
- 说明文字：如"还未查询到海关总署的信息，还不能报关"
- 图片URL：如 `https://splider.dadaex.cn/api/static/screenShot/177IAHAHS2005852.jpg`

如果是图片URL，回复时告知客户："舱单截图已生成，链接：{URL}"

# 舱位 API

## 接口信息
- **方法**：POST
- **地址**：`https://www.dadaex.cn/api/vn/position/getPositionByAi`

## 入参

| 参数 | 说明 | 是否必填 | 格式/说明 |
|------|------|---------|---------|
| carrier | 船公司 | 选填 | 船公司英文名大写，如 `COSCO` |
| port | 目的港 | 必填 | 港口英文名小写，如 `singapore` |
| userId | 用户ID | 必填 | 从 session 提取数字部分，如 session=`agent%3Amain%3A001` → `001` |
| groupId | 组ID | 忽略 | 不传 |
| routeCode | 航线代码 | 选填 | 如 `CME`，未知传 `""` |
| route | 航线名称 | 选填 | 如 `东南亚线`，未知传 `""` |
| delayDate | ETD开船时间 | 选填 | `YYYY-MM-DD`，未提及传 `""` |
| portType | 巴生港类型 | 条件填写 | 仅目的港为巴生港时：`NORTH` / `WEST` / `""`  |
| type | 直达/中转 | 选填 | `N`=直达，`Y`=中转，未指定传 `""` |
| zalo | - | 忽略 | 不传 |

## 出参说明

### 价格字段（重要：key 是动态的）
- 格式：`目的港{港口名}价格` 或 `目的港{港口名}暗放价格`
- 例：`目的港SINGAPORE价格`、`目的港PORT KELANG暗放价格`
- 值格式：`20GP/40GP/40HQ`，用 `/` 分隔
- **解析时必须遍历所有 key，不可硬编码**
- "价格" = 正常报价；"暗放价格" = 内部优惠价

### 其他字段

| 字段 | 说明 | 注意 |
|------|------|------|
| 船公司 | 如 `COSCO` | |
| 船期ETD | 开航日期 | |
| 晚开日期 | 截关日期 | 重要销售信息 |
| 剩余仓位 | 数字 | ≤2 时需提示紧张 |
| 船名/航次 | 合并字段 | 含船名和航次 |
| 现舱港 | 如 `PORT KELANG,SINGAPORE` | 逗号分隔多个挂靠港 |
| 起运港码头 | 如 `明东(外5)` | 可能为 `null`，展示时显示"待确认" |
| 航线代码 | 如 `CME` | |
| 航线名称 | 可能为空字符串 | |
| 备注 | 可能为空字符串 | |
| 中转港 | 如 `SINGAPORE` | |

> data 数组可能包含多条记录（多个航次），需全部展示

## 调用示例

```json
{
  "carrier": "COSCO",
  "port": "singapore",
  "userId": "001",
  "routeCode": "CME",
  "route": "",
  "delayDate": "2026-04-17",
  "portType": "",
  "type": ""
}
```

## 错误处理
任何情况下不能卡住，统一处理：
- status=0 或无数据 → "暂时没有查到舱位信息，请稍后重试。"
- 网络超时 → "查询超时，请稍后重试。"
- 返回异常 → "舱位查询出现问题，请稍后重试。"

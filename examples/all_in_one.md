# 示例：运价 + 舱位 + 船期（三合一）

## 场景
客户同时询问运价、舱位和船期。

## 对话

**客户：** 帮我查一下上海到巴生，价格、舱位、船期都要，走长荣

**意图识别：** `FREIGHT` + `POSITION` + `SCHEDULE`

**参数提取：**
```json
{
  "start_port": "shanghai",
  "end_port": "port klang",
  "carrier": "EVERGREEN",
  "etd": "",
  "hhtime": "",
  "routeCode": "",
  "route": "",
  "type": "",
  "portType": ""
}
```

**追问（可选）：** "请问走巴生北港还是西港？"
（若客户未说，portType 传空，直接调用）

**调用策略：**
1. 先调运价API
2. 从运价返回提取：航线代码、航线名称、船名、航次
3. 并行调用舱位API 和 船期API（携带从运价提取的补充参数）

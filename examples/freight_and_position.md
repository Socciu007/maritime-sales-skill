# 示例：运价 + 舱位（复合查询）

## 场景
客户同时询问运价和舱位。

## 对话

**客户：** 上海到新加坡多少钱，有没有位？

**意图识别：** `FREIGHT` + `POSITION`

**参数提取：**
```json
{
  "start_port": "shanghai",
  "end_port": "singapore",
  "carrier": "",
  "etd": "",
  "hhtime": ""
}
```

**调用策略：**
1. 先调运价API
2. 从运价返回中提取：航线代码 `KMSK/S`、航线名称 `东南亚线`、船名 `ZHONG GU YING KOU`、航次 `2603S`
3. 携带上述参数调用舱位API（参数更完整，结果更准确）

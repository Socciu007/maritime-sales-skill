# 示例：附加费查询

---

## 场景A：目的港+船司

**客户：** 新加坡马士基附加费多少

**意图识别：** `SURCHARGE`

**参数提取：**
```json
{
  "start_port": "SHANGHAI",
  "end_port": "SINGAPORE",
  "carrier": "MAERSK",
  "routeLine": ""
}
```

**期望回复：**

---

上海 → 新加坡（MAERSK）本地附加费：

**按票费用：**
- 电放费：¥300 / 票
- 文件费：¥450 / 票
- 舱单费：¥53 / 票

**按箱费用：**
- 码头操作费：20GP ¥670 / 40GP ¥1,020 / 40HQ ¥1,020
- 订舱费：20GP ¥240 / 40GP ¥350 / 40HQ ¥350
- 封条费：¥30 / 箱

可做 SEAWAY。

---

## 场景B：航线名称+船司

**客户：** 东南亚线 KMTC 本地费

**意图识别：** `SURCHARGE`

**参数提取：**
```json
{
  "start_port": "SHANGHAI",
  "end_port": "",
  "carrier": "KMTC",
  "routeLine": "东南亚线"
}
```

---

## 场景C：缺少船司（追问）

**客户：** 新加坡附加费

**意图识别：** `SURCHARGE`

**缺参：** carrier 为空

**期望回复：** 请问您要查哪家船司的附加费？

---

## 场景D：缺少目的港和航线（追问）

**客户：** 马士基本地费多少

**意图识别：** `SURCHARGE`

**缺参：** end_port 和 routeLine 都为空

**期望回复：** 请问您要查哪个目的港或哪条航线的附加费？

---

## 场景E：系统没有收录

**API 返回：**
```json
{ "code": 0, "data": [], "message": "抱歉系统暂未收录该航线附加费" }
```

**期望回复：** 抱歉，系统暂未收录该航线附加费。

---

## 场景F：懒人输入

**客户：** 新加坡中远本地费

**理解：** 查上海→新加坡 COSCO 附加费
**参数：** end_port=SINGAPORE，carrier=COSCO

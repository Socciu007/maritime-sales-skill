# 示例：停航查询

---

## 场景A：查某船司停航

**客户：** ONE 最近有没有停航

**意图识别：** `SUSPENSION`

**参数提取：**
```json
{ "shipCompany": "ONE", "routeCode": "" }
```

**期望回复：**

---

ONE 近期停航信息：

| 航线代码 | 原计划开航日 | 重新安排开航 |
|---------|-----------|------------|
| GS2 | 2026-04-30 | 暂无安排 |
| AG3 | 2026-04-29 | 暂无安排 |
| RCS | 2026-04-24 | 暂无安排 |
| GS2 | 2026-04-23 | 暂无安排 |

---

## 场景B：查所有停航（不指定船司）

**客户：** 最近有没有停航

**意图识别：** `SUSPENSION`

**参数提取：**
```json
{ "shipCompany": "", "routeCode": "" }
```

直接调用 API，不需要追问，返回所有船司的停航数据。

---

## 场景C：查某航线停航

**客户：** GS2 航线有没有停航

**意图识别：** `SUSPENSION`

**参数提取：**
```json
{ "shipCompany": "", "routeCode": "GS2" }
```

---

## 场景D：懒人输入

**客户：** 马士基 blank sailing

**意图识别：** `SUSPENSION`

**参数提取：**
```json
{ "shipCompany": "MAERSK", "routeCode": "" }
```

---

## 场景E：无停航数据

**API 返回：**
```json
{ "停航的船期": "未查询到停航信息" }
```

**期望回复：** 近期没有查到 MAERSK 的停航信息。

---

## 场景F：有晚开时间

**API 返回某条记录：**
```json
{
  "船公司": "ONE",
  "航线代码": "GS2",
  "开航日": "2026-04-30",
  "晚开时间": "2026-05-07"
}
```

**回复格式：**
- GS2：原计划 2026-04-30 停航，重新安排开航时间为 2026-05-07

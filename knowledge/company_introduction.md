## 一、公司简介

上海泛远国际货运代理有限公司属**国际一级货运代理有限公司**，是一家为直客提供服务的货代公司。

成立至今，始终秉承**专业、优质、诚信、高效**的服务理念。

公司有雄厚的经济基础、强大的全球关系网络、完善的人员配置，有较好的口碑和信誉。

在海运领域、仓库领域、地面物流领域内是很多商家的首选合作伙伴！

### 一体化服务
- 海运输
- 陆运输
- 门到门运输
- 仓储
- 报关

### 企业特点
与船东、港区、海关保持自有线上平台数据互通，以客户至上的经营理念，为客户提供周密专业的运输方案，让顾客放心、安心、省心！

## 二、企业发展史

| 年份 | 事件 |
|------|------|
| 1998年 | 集团总部cargonline在香港成立，一举成为香港往来航线总代理，全面负责上海70%的香港航线 |
| 2002年 | 集团总部扩展至上海建立上海泛远分公司，并在同年获得一级货代资质，与KMTC、COSCO、ONE等知名船公司开展长期合作 |
| 2005年 | 获得首批海事委员会(FMC)批核"NVOCC"无船承运人资质证书 |
| 2006年 | 市场战略重心转移至上海泛远分公司 |
| 2014年 | 上海泛远成功创办越南分公司并设立胡志明会计事务所，同年广西崇左分公司成立 |
| 2016年 | 成立上海恒链与子公司联合打造一站式电商物流，提供线上服务 |
| 2021-2024年 | 上海泛远相继在国内国外设立分公司（武汉、深圳、马来西亚、老挝等） |

## 四、主营业务

### 主营航线
全口岸：东南亚、中东、印巴、红海、南美、欧洲、非洲线等热门航线

### 航线特色

**东南亚线（王牌航线）**
- 主推荐船司：ONE、COSCO、KMTC、IAL、EMC、JJ、TSL、RCL、SITC
- 泛远在东南亚是绝大多数海运船司的庄家
- 淡季也能提供优势竞争价格，旺季满足大量客户对舱位的需求
- 船期固定，发船率高

**印巴中东线**
- 主推荐船司：ONE、IAL、KMTC、OOCL、TSL、COSCO、MCC

**非洲线**
- 主推荐船司：MSK、PIL、CMA、COSCO、OOCL、KMTC、RCL

**南美线**
- 主推荐船司：EMC、COSCO、OOCL

**欧洲线**
- 主推荐船司：YML、ONE、COSCO、MSC、MSK

## 五、服务网络

### 车队
- 承接各类干货集装箱、散货集装箱、冷藏箱集装箱、框架集装箱业务
- 配备GPS定位系统
- 自雇司机集卡20辆以上
- 24小时随时待命
- 逢年过节保证车辆配备完整

### 仓库
- 地址：上海市浦东新区丽正路1818号立体西库灏泽仓库
- 位于上海港外高桥外港附近
- 对于出口内装特别是出口集拼的业务具有地理位置优势
- 可在最短时间内装箱进港

### 海外服务
- 东南亚、中东、印巴、欧洲、日韩均有服务
- 国外清关配送服务
- 目的港清关服务价格优势明显
- 1-3天出运价

## 六、线上订舱

### 官网
http://www.sfyf.cn/

### 线上订舱优势
- 无需托书也可订舱
- 已有托书可直接进行识别，省去填写订单信息时间
- 线上订舱享有一定比例优惠政策
- 可通过公众号绑定线上账号第一时间了解订单实时进度

### 线上vs线下对比

| | 线下订舱 | 线上订舱 |
|---|---|---|
| 托书 | 需要 | 无需 |
| 运价 | 公开运价 | 内部运价 |
| 截单 | 按传统流程制作托书等待操作发放预配 | 一键截单 |
| 盯箱 | 需要时刻关注 | 自动提醒 |
| 时效性 | 较低 | 高 |

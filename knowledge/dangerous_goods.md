## 一、危险品9大类

### 第1类 爆炸品
| 类别 | 说明 |
|------|------|
| 1.1项 | 有整体爆炸危险的物质和物品 |
| 1.2项 | 有进射危险，但无整体爆炸的物质和物品 |
| 1.3项 | 有燃烧危险并有局部爆炸危险或局部迸射危险 |
| 1.4项 | 不呈现重大危险的物质和物品 |
| 1.5项 | 有整体爆炸危险的非常不敏感物质 |
| 1.6项 | 无整体爆炸危险的极端不敏感物品 |

### 第2类 气体
| 类别 | 说明 |
|------|------|
| 2.1项 | 易燃气体 |
| 2.2项 | 非易燃无毒气体 |
| 2.3项 | 毒性气体 |

### 第3类 易燃液体
具有闪点的液体，如汽油、酒精等

### 第4类 易燃固体
| 类别 | 说明 |
|------|------|
| 4.1项 | 易燃固体 |
| 4.2项 | 易于自燃的物质 |
| 4.3项 | 遇水放出易燃气体的物质 |

### 第5类 氧化性物质和有机过氧化物
| 类别 | 说明 |
|------|------|
| 5.1项 | 氧化性物质 |
| 5.2项 | 有机过氧化物 |

### 第6类 毒物质和感染性物质
| 类别 | 说明 |
|------|------|
| 6.1项 | 毒性物质 |
| 6.2项 | 感染性物质 |

### 第7类 放射性物质
| 级别 | 说明 |
|------|------|
| I级 | 白色标志 |
| II级 | 黄色标志，有运输指数 |
| III级 | 黄色标志，有三条垂直红色短杠 |
| 裂变性物质 | 特殊标志 |

### 第8类 腐蚀性物质
对金属、皮肤等有腐蚀性的物质

### 第9类 杂项危险物质和物品
如锂电池、干冰等

## 二、危险品订舱所需资料

订舱时必须提供：
- **Class Number**（危险品类别编号）
- **UN Number**（联合国危险货物编号）
- **危险品包装证书**

### 重要提示
**危险品订舱后数据不可更改！**

---

## 三、MSDS 化学品安全技术说明书

**全称：** Material Safety Data Sheet
**别称：** SDS（欧洲）、安全技术/数据说明书

### MSDS包含内容（共16项）
1. 物料及企业标识
2. 材料组成和成分信息
3. 危险标识
4. 急救措施
5. 消防措施
6. 泄漏应急处理
7. 操作处置与储存
8. 接触控制和个人防护
9. 理化特性
10. 稳定性和反应活性
11. 毒理学信息
12. 生态学信息
13. 废弃处置
14. 运输信息
15. 法规信息
16. 其他信息

---

## 四、化工品订舱所需资料

根据不同船公司要求通知，部分需要：
- **MSDS**（化学品安全技术说明书）
- **非危保函**（非危险品保函）
- 部分船公司还要有**运输鉴定书**

---

## 五、特种箱订舱所需资料

- 货物尺寸
- 毛重
- 目的港
- 品名
- 最好提供货物照片

### 特种箱箱型
| 箱型 | 说明 |
|------|------|
| 20OT / 40OT | 20尺/40尺开顶箱 |
| 20FR / 40FR | 20尺/40尺框架箱 |
| 20RF / 40RF | 20尺/40尺冷冻箱 |
| 40HR | 40尺高箱（冷藏） |
| 20TK | 20尺油罐箱 |

### 冷箱特别注意
订舱时需提供：
- **温度**（多少度）
- **是否开通风口**

## 六、危险品储存方式

| 方式 | 说明 |
|------|------|
| 隔离贮存 | 同一房间内，物料之间分开一定距离 |
| 隔开贮存 | 用隔板或墙将禁忌物料分离开 |
| 分离贮存 | 在不同建筑物或远离所有建筑的外部区域内 |

**禁忌物料：** 化学性质相抵触或灭火方法不同的化学物料

---

## 七、化工品储存要求

- 根据货物的物理性质和化学物质，设施专门区域
- 与普通货物分开储存
- 储存环境要求：通风、干燥、清洁
- 避免阳光直射，以免影响产品品质和使用效果

## 海外业务

| 姓名 | 职位 | 职责范围 | 咨询内容 |
|------|------|---------|---------|
| 周芳 | 海外业务负责人 | 海外询价、DDU、DDP | 海外目的港费用、海外送货地址确认 |

**海外询价收集模板（发周芳）：**
1. P.O.L : 起运港
2. P.O.D : 目的港
3. VOLUME : 箱型箱量
4. G.W Weight : 毛重
5. HS CODE : 货物HS CODE
6. COMMODITY : 品名
7. CARGO VALUE : 货值（DDP条款下涉及税金估算用）
8. DELIVERY ADDRESS : 国外送货地址

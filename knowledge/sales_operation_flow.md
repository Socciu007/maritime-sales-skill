# 销售与操作单证对接业务全流程

> 来源：day2销售操作对接流程详情.docx
> 整理时间：2026-05-23

---

## 一、销售订舱环节

### 1. 客户需求获取
销售部门与客户沟通，了解海运需求：货物信息、目的地、运输方式、特殊要求等

### 2. 报价与方案制定
- 根据客户需求制定海运方案
- 报价包括：运费、港杂费、报关费、拖车/内装费等各项费用
- 根据客户实际需求报价

### 3. 协商调整
与客户就方案进行协商，根据反馈进行调整

### 4. 订舱与合同签订
- 客户接受报价后，与操作部门负责人确认是否有仓位
- 通过客户托书进行系统EB订单建单
- 将泛远EB号发送给对应船司的操作人员预订舱位
- 确认船舶离港时间和航线

### 5. 合同签订
- **第一次合作客户**：双方签订海运合同
- **付款方式**：
  - 江浙沪客户可签署月结协议
  - 第一票付款买单
  - 其他地区客户合作初期皆按付款买单签署

### 6. 外拷订舱（我司不主营的船司）
- 进行系统建单后需要加上：发送EB号码给商务部工作人员确认价格与仓位
- 确认完毕后，再将泛远EB号发送给船司操作人员
- **外拷订舱前提**：需先从确认价格仓位开始，再到确认对方公司抬头、调查公司背景、向公司申请订舱口开通

## 二、操作单证环节

### 1. 单证制作
- 根据销售提供的订舱信息和客户需求提交订单信息
- 单证部门根据客户提供的单证信息上传：VGM、提单确认件、舱单
- 根据不同船司还会有各类保函

### 2. 报关
- 准备报关资料：提单、商业发票、装箱单等
- 根据目的地国家规定可能需要：原产地证、卫生检疫证书等特殊文件
- 如有文件缺失，协助我司专员王晓君将所需文件找客户凑齐

### 3. 拖车与仓库安排
- 客户订舱后，根据船期查询港行纵横了解开港情况
- 一旦有开港信息，和客户约定做箱时间
- 给到我司专员王晓君明确指令：货物是否进仓、收费方式、进仓时间
- 确认后将信息发给王晓君告知此票进仓
- 预配下达后进行预配发送
- 港行纵横有开港信息后提醒王晓君安排做箱

### 4. 订单跟踪关键节点
- 销售人员时刻跟踪订单进度
- 特别注意：客户的放单和提箱时间（找对应操作部门负责人对接）
- 临近截单时：找对应单证部门负责人了解截单时间
- 销售人员与单证人员同步提醒客户
- 客户箱子完成进港后：盯紧港区状态，直到箱子完成码头配载
- 进入收款流程

### 5. 特殊情况处理
- **如船司甩箱**：通知客户甩箱，后续单证部门在船开后发送甩箱通知给客户

### 6. 费用与开票
- 客户确认费用、开票、付款
- 由单证部门负责协助开票
- 销售人员负责催付

## 三、销售与操作单证对接信息传递

### 1. 信息传递原则
- 销售部门将客户的海运需求和特殊要求传递给操作部门
- **必须有文字留底备注**并备注在EB系统内
- 确保操作部门能够准确理解并执行

### 2. 单证交接
- **客户放单时如超额**：操作找销售放单
- 销售根据客户的合作情况和后续订单压单情况向上级领导申请

### 3. 申请模板
```
客户：
箱量：
申请：协议到期时间：
超额USD 额度USD
总费用USD
```

### 4. 后续循环单
- 正本提单和电放提单的申请可以在客户船开后进行
- **SWB提单申请**：务必在船开前向领导申请

## 四、注意事项

### 1. 文件留底
任何文件必须要客户在群内留底确认，确保所有信息准确无误

### 2. 问题分类
- **关于提单和目的港问题**：问单证
- **关于舱位、船期、品名**：问操作

### 3. 船司特点（需掌握）
- KMTC：放单后有亏仓费
- COSCO：可以自选提箱点

### 4. 核心理念
对每一票订单详细了解对应公司的规则，把对应船司的服务特点抓明白，多沟通多请教，做好内部沟通。
